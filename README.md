Aan – News Website 

About the Project
Aan is a news website project designed to display news from different categories in one place. The website provides a simple interface where users can browse news articles and view their details.

The project is currently **under development**, and more features and improvements will be added.

Current Features
- News Categories: Sections for Sports, Entertainment, and Business news.
- News Cards: Display news images, titles, sources, and dates.
- News Details Page: A dedicated page to display a news article with its title, image, date, source category, and content.
- Weather Section: Displays weather information for Assiut.
- Currency Rates: Shows sample exchange rates for different currencies.
- Live Matches Section: Displays a basic layout for football match scores.
- Navigation Bar: Includes navigation menus for currency conversion and sports-related sections.
- Responsive Layout: Uses Bootstrap grid classes to help organize the layout across different screen sizes.

Technologies Used
- HTML5
- CSS3
- Bootstrap 5

Project Pages
- Home Page: Displays news categories, news cards, weather, currency rates, and live match sections.
- News Details Page: Displays the details and content of a selected news article.

Project Status
In Progress

The project is still under development. Some sections currently contain placeholder content or sample data. Additional pages, functionality, styling, and improvements may be added as development continues.

How to Run
1. Download or clone the project repository.
2. Keep the HTML files and required assets in their correct folders.
3. Make sure the images referenced in the code are available at the specified paths.
4. Open the home page (`home.html`) in your browser.
